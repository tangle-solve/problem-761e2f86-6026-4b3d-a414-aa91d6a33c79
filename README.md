### ALGO-000087: Dynamic optimality of Greedy BST
- **Subfield:** Communication complexity and adaptive data structures
- **Open:** Prove constant competitiveness of the online Greedy BST algorithm against the offline optimum.
- **Status:** Long conjectured. Guo, Pettie, Skora, and Wan’s August 2026 preprint reports competitiveness \(2^{O(\sqrt{\log\log n})}\), not a constant.
